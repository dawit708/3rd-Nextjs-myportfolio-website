## Why Clean Code Matters

TypeScript gives us superpowers — but only if we use it well. After writing TypeScript for 3 years, here are the 10 tips I follow daily.

## 1. Avoid `any` Like the Plague

```typescript
// Bad — you lose all type safety
function process(data: any) { ... }

// Good — the compiler helps you
