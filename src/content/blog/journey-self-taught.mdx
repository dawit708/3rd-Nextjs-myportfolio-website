## The Beginning

Three years ago, I didn't know what a div was. Today, I've shipped 12+ full-stack applications. This is my story.

## Chapter 1: Curiosity

It started with a simple question: How do websites work?

I opened YouTube, watched a 4-hour HTML tutorial, and built my first page.

## Chapter 2: The First Aha Moment

I still remember the day I made my first button change color on click. That feeling changed everything.

## Chapter 3: The Grind

Learning to code is not glamorous. It's long nights, endless documentation, and failing 100 times before something works.

## Chapter 4: The Projects

Each project taught me something new:

- Calculator taught me DOM manipulation
- Weather App taught me API integration
- E-commerce taught me state management
- Hospital System taught me full-stack thinking

## What I'd Tell My Younger Self

1. Ship something every month. Small, ugly, but shipped.
2. Read code from open source. You'll learn more than any tutorial.
3. Ask for help. The dev community is generous.
4. Don't wait to feel ready. You never will.

I'm heading to Addis Ababa for an internship. The journey continues.
