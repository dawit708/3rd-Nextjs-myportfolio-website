## Why Vercel?

Vercel is made by the creators of Next.js, so it just works.

## Prerequisites

- A Next.js project on GitHub
- A Vercel account

## Step 1: Push Your Code to GitHub

Commit and push your changes to GitHub.

## Step 2: Connect to Vercel

Go to vercel.com and click New Project. Import your GitHub repository.

## Step 3: Add Environment Variables

Add your environment variables in Vercel's dashboard.

## Step 4: Deploy

Click Deploy. Vercel does everything automatically.

## Step 5: Custom Domain

Buy a domain, add it in Vercel, and update DNS records.

## Automatic Deploys

Every time you push to main, Vercel automatically redeploys.

## Tips for Production

- Use environment variables for API keys
- Enable analytics to monitor performance
- Set up a custom 404 page
- Add robots.txt and sitemap.xml

## Conclusion

Vercel makes deployment painless. Total time from push to live: under a minutes.
